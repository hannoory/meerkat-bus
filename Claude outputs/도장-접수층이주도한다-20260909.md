## 3. ★★★ 정한 것 — 묶어 되묻기 규칙

오빠가 「그 규칙을 정해야 해」라고 한 자리다. **아래가 그 규칙이다.**

1. **묶음은 「같은 종류(slot id)」로 만든다.** `amount#1`·`amount#2` → 「금액」 묶음 하나.
2. **한 묶음은 한 번에 묻는다.** 「금액을 알려주세요 — 첫째 건 / 둘째 건」
3. **묶음 차례는 옷 선언 순서**를 따른다. 킷이 새 순서를 지어내지 않는다.
4. **한 번에 낼 묶음 수 = 1 이 기본.** 오빠 예시가 그대로 성립한다:
   - 금액 둘만 비면 → **묶음 하나 → 한 번에**
   - 종목 하나 + 금액 둘이 비면 → **종목 묶음 → 금액 묶음 = 두 번**
   ★ 이 값(`maxAskGroups`)은 **9/2 도장의 「고르는 자리 셋」**을 그대로 탄다 — 팩 → 프로그램 → 사용자 순으로 덮는다. 킷은 셋 다 지원만 한다.
5. **답은 종류가 섞여 와도 제자리에 꽂는다.** 「종목 하나 + 금액 둘」, 「금액 하나 + 방향 둘」 —
   ★ 이건 **새 기능이 아니라 이미 있는 자리**(`answer.ts` + `sheet.ts` 의 `mergeGroups`)다.
   **다만 「종류가 여럿 섞인 한 문장」이 실제로 다 꽂히는지는 아직 안 쟀다** — 재고 나서 고친다.
6. **되물을 땐 남은 것만.** (9/2 도장 §3 그대로 — 물음이 점점 줄어든다)
7. **다 차면 되읽기 + 확인.** 「이렇게 이해했습니다 … **심의할까요? / 고칠래요**」
8. **「심의」를 누르면 완료 신호와 값을 앱에 넘긴다.** ← 이 자리가 지금 **없다.**
