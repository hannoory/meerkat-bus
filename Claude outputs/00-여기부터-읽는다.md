## ★ 촬영할 때 칠 것 — 이게 전부다

```bash
bash tools/shoot-prep.sh          # 무대 켠다 (내릴 때: -Down)

bun run tools/intake-trace.ts --fixture      # 층 일곱이 찍히는 판(6장 그림)

bun --env-file=.env --env-file=.env.live run tools/intake-trace.ts \
    --live --repeat 3 --pack pension-kr "반도체 ETF 300만원어치 매도하고, 로봇 200만원 삽니다"
                                             # 같은 문장 3회 — 판정 입력 해시 대조
```

**안전 문장** — 연금 「반도체 ETF를 500만원 추가매수하려고 합니다.」 / 대출 「카드론으로 40 새로 빌리려 합니다.」
연금 → 대출 전환은 **서버 창만** 다시 켜면 된다(`PACK_ID=loan-kr bun run server`) — 약 **6.2초**.

★ ✗ **연기를 고르지 마라.** 여러 번 돌려 「흔들리는 장면」을 사냥하지 않는다.
결과를 고르는 것과 연기를 고르는 것은 다르다. 한 번 돌리고 **나온 대로** 쓴다.

## 지켜야 할 것 (오빠 확정)

- **「우리/저희」 금지 → 「저」** · **내부 용어는 풀어서** 말한다
- **용어**: 「낱말표」 대신 **파서**, 그 하나의 모델은 **LLM**(여러 모델·일반론은 「모델」 그대로), 「갈렸다」 대신 **달랐다**
- ★ **「LLM 이 언제나 낫다」고 말하지 마라** — 「이번 달」을 종목으로 다섯 번 다 잘못 읽은 반례가 있다
- ★ **6장 대출 예시**는 `통과 0 · 거부 2` 라 「못 하네」로 보인다. 반드시 한 마디:
  「**일부러 넣은 거절 표본입니다. 막히는 게 실패가 아니라, 막힐 때 이름이 붙는 게 설계입니다.**」
- ★ **6장에서 짚을 문장 하나**: 「**첫 층만 AI, 나머지 여섯은 코드입니다**」
- ★ **원칙 다섯의 진짜 이름** = P1 섹터집중 · P2 분할집행 · P3 물타기 · P4 냉각 · P5 변경사유
- ★ **시계 확인 지점**: 2:20 / 5:05 / 7:45 / 9:55 / 11:40
- ★ **예시 구성**: 충동구매로 시작 → 연금으로 시연. **바꾸지 마라**
- ★ **금지선**: 매수/매도/종목 추천 없음. 정보·대조·반론만. **결정은 사용자**
- ★★ **발표엔 한 줄만.** 상세(K=9 · 봉투 해시 · leftover · 510회 셋의 뜻)는 **`08` 답변카드 몫**이다 —
  오빠: 「어차피 발표 시간 안에 상세히 말은 못 한다」
